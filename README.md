# .github

Default community health files for the public repositories under
[github.com/sapn95](https://github.com/sapn95).

GitHub falls back to this repository whenever one of mine does not carry its own
copy of one of these files, so the rules live in one place instead of in eleven
copies that drift apart. A repository that needs something different ships its
own version, and that one wins.

| File | What it is for |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute. Short version: anyone with a GitHub account may open a pull request, no invitation and no CLA. |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Argue about the code, not about the person who wrote it. |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately, and where the risk actually is. |
| [SUPPORT.md](SUPPORT.md) | Where a question goes. |
| [CI.md](CI.md) | What every repository's workflows are expected to have in common, and why there is no pre-commit framework. |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE) | Bug report and feature request forms. Blank issues stay available. |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | What a pull request description should answer. |

There is deliberately no `profile/README.md` here. That file would replace the
account's profile page, which is a separate decision from these defaults.
